# Guide d'utilisation - Heart

Bienvenue sur **Heart**, votre site pour organiser, gérer et partager vos photos ou images. Ce guide vous accompagne dans la prise en main de toutes les fonctionnalités de l'application.

## 1. Démarrage

### Inscription et Connexion

1. Accédez à la page d'accueil et cliquez sur **Inscription**.
2. Renseignez vos informations et choisissez un mot de passe sécurisé.
3. Une fois votre compte créé, connectez-vous avec vos identifiants pour accéder à votre tableau de bord.

## 2. Gestion des Albums

### Créer un album

- Cliquez sur le bouton **"Créer un album"**.
- Saisissez un titre et une description pour donner du contexte à vos souvenirs.
- Sélectionnez le niveau de visibilité souhaité :
  - **Public** : Visible par tous les utilisateurs de la plateforme.
  - **Privé** : Visible uniquement par vous-même.
  - **Restreint** : Accessible uniquement aux personnes que vous invitez explicitement.

### Éditer et enrichir vos albums

- Dans votre espace **"Mes Albums"**, cliquez sur l'icône d'édition.
- Vous accéderez à une interface centralisée pour modifier vos informations, gérer la visibilité et assigner des tags à votre album.
- **Ajout de photos** : Utilisez la zone "Glisser-déposer" pour charger vos images. Le système accepte les formats JPG, PNG et WEBP.

## 3. Partage et Collaboration

### Gérer les accès restreints

- Pour un album en mode **Restreint**, utilisez le bouton **"Gérer les accès"**.
- Invitez d'autres utilisateurs via leur nom d'utilisateur.

### Partage rapide

- Cliquez sur le bouton **"Copier le lien"** présent sur la page de votre album. Vous pouvez ensuite transmettre cette URL à vos proches pour un accès direct.

## 4. Organisation et Interactions

### Organisation par Tags

- Associez des étiquettes (ex: "Jeux vidéos", "Voyage", "Peinture") à vos photos.
- Utilisez les filtres dynamiques en haut de page pour trier et retrouver rapidement des photos spécifiques parmi vos albums.

### Commentaires

- Cliquez sur une photo pour l'afficher en grand.
- Partagez vos impressions dans l'espace commentaire.
- Vous avez la possibilité de **modifier** ou de **supprimer** vos propres messages à tout moment.
